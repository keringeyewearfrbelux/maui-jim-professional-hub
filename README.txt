Maui Jim Professional Hub — GitHub Pages package

Purpose:
A desktop-first and mobile-responsive GitHub Pages landing page for a professional email signature.

Files to upload at the root of a NEW GitHub repository:
- index.html
- assets/
- README.txt

IMPORTANT ASSET STEP:
Add your 1080p video file into the assets folder and name it exactly:
Maui Jim Video.mp4

Add your white Maui Jim logo PNG into the assets folder and name it exactly:
Maui Jim Logo White.png

Important: GitHub is case-sensitive. Keep the exact spelling, spaces and extensions.

Current page behavior:
- Full-screen video hero with centered text.
- If the logo is missing, a simple MAUI JIM text fallback appears.
- Two transparent buttons:
  1. Access to your B2B platform & SAV
  2. Communicate with our assets

After upload to GitHub Pages:
1. Create a new public repository, e.g. maui-jim-professional-hub.
2. Upload index.html, assets/, README.txt.
3. Add the video and logo files in assets with exact names.
4. Activate GitHub Pages from Settings > Pages > Deploy from branch > main > /root.
5. Test on desktop and iPhone before adding to Outlook signature.
